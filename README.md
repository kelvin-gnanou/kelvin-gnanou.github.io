## Run Locally

```bash
git clone https://github.com/kelvin-gnanou/kelvin-gnanou.github.io.git
cd kelvin-gnanou.github.io
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser. Use a local server so the JavaScript modules load correctly.

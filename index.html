About

Driven by fundamentals, oriented toward intelligence.

I'm a first-year Computer Engineering student at École Mohammadia d’Ingénieurs (EMI), Morocco. My approach to computing begins with understanding how things work beneath the surface: how data is represented, how algorithms operate, and how software is structured.

This interest has led me to explore programming in C and C++, implement data structures from scratch, work with memory management, and develop a disciplined workflow using Linux, compilers and debugging tools.

Beyond software engineering, I'm interested in the mathematical ideas behind computation: algorithmic complexity, optimization, statistical reasoning and mathematical modelling. I'm gradually extending these foundations toward data science and machine learning.

My long-term objective is to explore artificial intelligence at a deeper level — not only applying existing methods, but understanding the computational and mathematical principles that make intelligent systems possible.

libds — Data Structures Library

An evolving C11 library designed to implement and expose fundamental data structures through a reusable static library. The project combines low-level programming with modular architecture, a public API, and a dedicated testing workflow.

  • Stack, queue and singly linked list
  • Binary search tree and graph implementation
  • Reusable static library (libds.a)
  • Public headers and modular implementation
  • Interactive demonstration and unit tests
  • Debug, release and sanitizer build configurations
  • Library installation and uninstallation targets
